## 🎯 Features

### All Files Support:
- ✅ **Auto dependency install** - Checks and installs missing packages
- ✅ **Backend + Frontend** - Starts both automatically
- ✅ **uv support** - Uses uv if available
- ✅ **Graceful shutdown** - Handles Ctrl+C properly
- ✅ **Keep window open** - Don't miss error messages
- ✅ **Status display** - Shows running processes

### Command-Line Options (edit file to use):
- `--port PORT` - Custom port (default: 8501)
- `--poll-interval MINUTES` - Backend poll interval (default: 15)
- `--backend-only` - Start only backend
- `--frontend-only` - Start only frontend
- `--dry-run` - Run backend in dry-run mode
- `--verbose` - Enable verbose logging

---

## 🛑 Stopping

Press `Ctrl+C` in the terminal/Command Prompt window to gracefully stop all processes.

---

## 🐛 Troubleshooting

### macOS: "Permission Denied"

```bash
chmod +x start_automation.command
```

### Windows: "Python is not installed"

Install Python from https://python.org and check "Add Python to PATH"

### Window Closes Too Fast

Open terminal manually and run the script from there to see error messages.
