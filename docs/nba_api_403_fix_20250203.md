# NBA API 403 Error Fix - 2025-02-03
**Date:** 2025-02-03  
**Status:** FIXED ✅  
**Issue:** Boxscore API returning 403 for games that haven't started yet

---

## Summary

Fixed 403 Forbidden errors when fetching data from NBA.com boxscore API for games that haven't started yet. The system now gracefully falls back to schedule API for basic game information.

---

## Problem

### Symptoms
```
Failed to fetch game 0022500721: 403 Client Error: Forbidden for url: https://cdn.nba.com/static/json/liveData/boxscore/boxscore_0022500721.json
```

**Root Causes:**

1. **Boxscore API Unavailable for Future Games**
   - Boxscore API (`cdn.nba.com/static/json/liveData/boxscore/boxscore_{game_id}.json`) only returns data for:
     - Games currently in progress
     - Recently completed games
     - Games very close to starting time
   - Future games (not started yet) return 403 AWS S3 AccessDenied

2. **No Fallback Mechanism**
   - When boxscore returned 403, entire prediction failed
   - No alternative data source
   - Unable to get team names for prediction
   - Games 0022500721-0022500725 (later games on 2026-02-03) failed

3. **Database Storage Issue**
   - Discord posts with `id=None` (webhook returned 204) were not being stored in database
   - Only posts with message IDs were stored
   - No audit trail for posts

4. **Rate Limiting on Successive Requests**
   - Making multiple API requests too quickly caused rate limiting
   - First 4 games succeeded, then 6 failed
   - Need delay between requests

## Solutions

### 1. Added Schedule API Fallback in `src/data/game_data.py`

**Location:** `src/data/game_data.py`

**Problem:** `fetch_game_by_id()` only tried boxscore API, returned None on 403

**Solution:** Added special handling for 403 errors to fall back to schedule API:

```python
def fetch_game_by_id(game_id: str) -> Optional[Dict[str, Any]]:
    """Fetch game data by ID from boxscore API."""
    try:
        data = fetch_json(CDN_BOX.format(gid=game_id))
        game = data.get("game")
        if not game:
            return None
        return game
        
    except requests.HTTPError as e:
        # Special handling for 403 errors
        if e.response.status_code == 403:
            # Game not started yet or boxscore not available
            # Try to get basic info from schedule
            logging.info(f"Boxscore not available for {game_id} (game not started), checking schedule")
            return _get_game_from_schedule(game_id)
        else:
            logging.warning(f"Failed to fetch game {game_id}: {e}")
            return None
```

**Added New Function:** `_get_game_from_schedule()`

```python
def _get_game_from_schedule(game_id: str) -> Optional[Dict[str, Any]]:
    """
    Get basic game info from schedule API (fallback when boxscore unavailable).
    
    Returns minimal game dict with homeTeam, awayTeam info.
    """
    try:
        # Fetch schedule
        SCHEDULE_URL = "https://cdn.nba.com/static/json/staticData/scheduleLeagueV2.json"
        response = requests.get(SCHEDULE_URL, timeout=30, headers=NBA_HEADERS)
        response.raise_for_status()
        data = response.json()
        
        # Search for the game in schedule
        league = data.get('leagueSchedule', {})
        game_dates = league.get('gameDates', [])
        
        for gd in game_dates:
            games = gd.get('games', [])
            for game in games:
                if game.get('gameId') == game_id:
                    # Found the game - return minimal game dict
                    return {
                        'gameId': game_id,
                        'gameStatus': 1,  # Scheduled
                        'gameTimeUTC': game.get('gameTimeUTC', ''),
                        'homeTeam': {
                            'teamId': game.get('homeTeam', {}).get('teamId', ''),
                            'teamTricode': game.get('homeTeam', {}).get('teamTricode', ''),
                            'teamName': game.get('homeTeam', {}).get('teamName', ''),
                            'teamCity': game.get('homeTeam', {}).get('teamCity', ''),
                            'periods': []  # No period data before game starts
                        },
                        'awayTeam': {
                            'teamId': game.get('awayTeam', {}).get('teamId', ''),
                            'teamTricode': game.get('awayTeam', {}).get('teamTricode', ''),
                            'teamName': game.get('awayTeam', {}).get('teamName', ''),
                            'teamCity': game.get('awayTeam', {}).get('teamCity', ''),
                            'periods': []  # No period data before game starts
                        },
                        'gameClock': 'PT00M00.00S',
                        'period': 0
                    }
        return None
    except Exception as e:
        logging.warning(f"Failed to get game {game_id} from schedule: {e}")
        return None
```

**Impact:**
- When boxscore API returns 403, automatically falls back to schedule API
- Gets basic game info: team tricodes, names, game status
- Structure matches boxscore format for compatibility
- Predictions can proceed with schedule data

### 2. Added Rate Limiting Delay in `worker/runner.py`

**Location:** `worker/runner.py` in `_process_daily_summary()`

**Problem:** Making predictions for all games too quickly caused rate limiting

**Solution:** Added 5 second delay between game predictions:

```python
# Generate predictions for all games
predictions = []
for game in games:
    game_id = game['game_id']
    
    try:
        # Add delay between requests to avoid NBA API rate limiting
        if predictions:  # Don't delay on first game
            import time
            time.sleep(5)  # 5 second delay between games to avoid 403 errors
        
        # Get pregame prediction
        from src.predict_api import predict_game
        result = predict_game(
            game_input=game_id,
            mode='pregame',
            fetch_odds=False  # Don't need odds for summary
        )
```

**Impact:**
- 5 second delay between game predictions
- Reduces API request rate to ~12 requests per minute
- Prevents rate limiting
- All 10 games now process successfully

### 3. Fixed Discord Post Storage in `worker/runner.py`

**Location:** `worker/runner.py` in `_process_daily_summary()`

**Problem:** Only stored Discord posts if webhook returned a message ID

**Issue Code:**
```python
message_id = self.discord_client.post_message(message)

if message_id:
    # Store post record
    DiscordPostStorage.store_post(...)
```

When webhook returns 204 No Content (common), `message_id` is None, so post not stored.

**Solution:** Always store post record, even if message_id is None:

```python
message_id = self.discord_client.post_message(message)

# Store post record (even if message_id is None - some webhooks return 204 without ID)
DiscordPostStorage.store_post(
    game_id=trigger['game_id'],
    trigger_type='DAILY_SUMMARY',
    channel_id='main',
    message_id=message_id if message_id else 'webhook-204',
    payload={
        'message': message,
        'predictions': predictions,
        'date': date
    },
    db_path=self.db_path
)
```

**Impact:**
- All Discord posts now stored in database
- Audit trail for all posts
- Can track webhook behavior

## Notes

- **Boxscore API Only Available:** When games are in progress or recently completed
- **Schedule API Always Available:** Has all scheduled games including future games
- **Fallback Strategy:** Try boxscore first, fall back to schedule on 403
- **Rate Limiting:** 5 second delay prevents too many rapid requests
- **Prediction Accuracy:** Schedule data sufficient for pregame predictions (team stats from historical data)
- **Live Data Required:** Halftime and Q3 models require live boxscore data (will fall back gracefully if unavailable)
