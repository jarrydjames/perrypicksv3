🔄 TRIGGER TYPES & TIMING
═══════════════════════════════════════════════════════════════════════════════

Time-Based (Scheduled):
  - PRE_3H  : 3 hours before tip (TTL: 3600s)
  - PRE_1H  : 1 hour before tip   (TTL: 1800s)
  - PRE_10M : 10 minutes before tip (TTL: 300s)

Game-State (Detected Live):
  - HALFTIME: Status='Halftime' OR period=2, clock='12:00'  (TTL: 300s)
  - Q3      : Period=3, clock='0:00' OR transition to Q4      (TTL: 300s)

Accuracy: All game-state triggers within 1 minute (60s poll interval)

📊 ODDS API OPTIMIZATION
═══════════════════════════════════════════════════════════════════════════════

Caching Logic:
  1. Check cache first (returns if valid)
  2. If cache miss or expired:
     - Call Odds API
     - Store result with TTL
     - Log API call with usage_reason

Result: ~97% reduction in API calls (as proven in v3)

TTL by Trigger Type:
  - PRE_3H   : 3600s (1 hour)  - Odds stable 3h out
  - PRE_1H   : 1800s (30 min)  - Odds volatile closer to tip
  - PRE_10M  : 300s  (5 min)   - Need fresh odds right before tip
  - HALFTIME : 300s  (5 min)   - Halftime betting opens
  - Q3       : 300s  (5 min)   - Q3 betting opens
  - PERIODIC : 600s  (10 min)  - Tracking polls

🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════════

1. Install dependencies:
   $ pip install -r requirements.txt

2. Configure environment:
   $ cp config/.env.example .env
   $ nano .env  # Add your ODDS_API_KEY and DISCORD_WEBHOOK_URL

3. Verify installation:
   $ python test_automation.py

4. Run automation:
   $ python -m worker.runner

Options:
  --once              : Run single cycle and exit (for testing)
  --dry-run          : Run without posting to Discord
  --poll-interval N  : Set poll interval to N seconds
  --date YYYY-MM-DD  : Process specific date
  --db-path PATH     : Use custom database path

📞 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: No triggers firing?
  Solution:
    $ sqlite3 data/automation.db "SELECT * FROM triggers WHERE status='scheduled'"
    $ date -u  # Check system time

Issue: Duplicate Discord posts?
  Solution: UNIQUE constraints prevent this. If still happening:
    $ sqlite3 data/automation.db \
      "SELECT game_id, trigger_type, COUNT(*) FROM triggers \
       WHERE fired_at_utc IS NOT NULL GROUP BY game_id, trigger_type \
       HAVING COUNT(*) > 1;"

Issue: Odds API rate limiting?
  Solution:
    $ grep "HTTP error fetching odds" logs/automation.log
    # Increase TTL values in core/data_sources.py
